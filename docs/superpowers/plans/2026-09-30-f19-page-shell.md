# F19 — Mise en page commune — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** les quatre pages examinateur (accueil, création, passage, stats) passent par une coque `PageShell` : barre de titre commune, bouton de thème toujours dernier à droite, contenu plafonné à 1536 px.

**Architecture:** un composant transverse `src/components/page-shell.tsx` que chaque page appelle en lui passant `title`, `back`, `meta`, `actions` et son contenu ; il est rendu là où la page l'est déjà (sous `SessionAppearance` pour le passage et les stats). Les en-têtes propres à chaque page sont réduits à leurs actions (`HomeActions`) ou à leur ligne d'infos (`PassageMeta`). La vue projetée n'est pas touchée.

**Tech Stack:** React 19, TanStack Router, Tailwind 4, shadcn (Base UI), Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-30-f19-page-shell-design.md`

## Global Constraints

- Largeur : `max-w-(--breakpoint-2xl)` (1536 px), centré (`mx-auto w-full`).
- Marges : `px-4 py-4 sm:px-6 sm:py-6 lg:px-10` ; `gap-6` entre barre et contenu.
- Barre : `<header className="flex flex-wrap items-start justify-between gap-3">`, gauche `flex min-w-0 flex-[1_1_20rem] flex-col gap-1` (back, `h1`, meta), droite `ml-auto flex flex-wrap items-center justify-end gap-2` (actions puis `ColorModeToggle`).
- `h1` : `text-2xl font-bold tracking-tight`.
- Barre non sticky, sans bordure.
- `ColorModeToggle` n'est jamais importé dans `src/features/` sauf `features/present/`.
- Arborescence D59 : imports `@/…`, pas de barrel, kebab-case, pas d'import entre features. `pnpm deps` doit rester vert.
- Commits gitmoji en français, présent, emoji Unicode, avec les lignes `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` et `Claude-Session: https://claude.ai/code/session_01EtRb32mHbi1w7WczeEkbh4`.
- Tests ciblés : `rtk proxy pnpm exec vitest run <fichier>` (ne pas lire `.vitest/json/output.json`, QUIRKS). Vérification complète : `pnpm check`.
- Textes et rôles existants inchangés (clés `app_title`, `create_title`, `back_home`, `stats_back`, libellé du thème `Mode d'affichage : …` / `Display mode: …`).

## Review Focus

1. Stats et passage en locale `en` : le bouton de thème de la coque doit être en anglais (`Display mode: …`) — la coque reçoit le `ui` pris **sous** `SessionAppearance`. Test : Task 4 (stats, config `locale: 'en'`).
2. Création : la garde de dépôt de page (`onDragOver` / `onDrop` sur `<main>`) doit continuer de fonctionner une fois passée par `...rest` de la coque. Test existant `create-session-page.test.tsx:126` (dragOver renvoie `false`) doit rester vert ; test de transmission dans Task 1.
3. Accueil stockage `unavailable` : pas de « Créer une session », le thème reste dernier. Test : Task 2.
4. Passage sans étudiant actif : pas de ligne d'infos, contrôles de projection et thème présents, thème dernier. Test : Task 3.
5. Titre d'examen très long à 1280 px : il passe à la ligne sans pousser le thème hors de l'écran (`min-w-0`). Non testable en jsdom : vérification visuelle (Task 5).
