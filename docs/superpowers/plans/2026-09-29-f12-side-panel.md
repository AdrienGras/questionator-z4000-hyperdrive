# F12 — Side panel, onglet « Étudiant » — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remplacer l'`aside` vide de F09 par un panneau latéral repliable à deux onglets ; l'onglet « Étudiant » montre les questions tirées (note corrigeable), les totaux, un commentaire sauvegardé automatiquement et la bascule d'absence.

**Architecture:** Transitions pures `editScore`, `setComment`, `setAbsent` dans `src/domain/passage/`, appliquées par `usePassageActions` via `updateSession`, qui n'écrit plus rien quand le mutator renvoie la session reçue (D67). La liste des questions et la liste des notes sortent de `FinalScreen` en composants partagés. L'état du panneau vit en `localStorage` ; le commentaire passe par un hook `useAutosave`.

**Tech Stack:** React 19, TanStack Router, Dexie (`updateSession`, liveQuery), Vitest + Testing Library + fake-indexeddb (faux minuteurs pour `useAutosave`), Tailwind 4 + shadcn/base-ui (`tabs`, `textarea` à ajouter ; `alert-dialog`, `button`, `label` existants).

**Spec:** `docs/superpowers/specs/2026-09-29-f12-side-panel-design.md` (décision D67 dans `docs/DECISIONS.md` ; D07, D08, D21, D65 pour le contexte).

## Review Focus

1. Frappe dans le commentaire puis changement d'étudiant (sélecteur) avant 500 ms : le commentaire est enregistré sur le **bon** étudiant, pas sur le nouveau — Task 2 (flush au démontage) et Task 6 (écran).
2. Corriger une note pendant que la question suivante est `pending` (étudiant en cours) : la correction passe, la question en cours reste intacte — Task 1 (domaine) et Task 5 (écran).
3. Déclarer absent un étudiant terminé et révélé avec ajustement, puis le décocher : il revient « à passer » sans ajustement ni `finalRevealedAt`, commentaire conservé — Task 1 et Task 6.
4. `localStorage` inaccessible (lève à la lecture et à l'écriture) : le panneau s'affiche ouvert sur « Étudiant » et se replie quand même pour la fenêtre — Task 2 et Task 5.
5. Sortie du champ commentaire sans modification : aucune écriture (`updatedAt` inchangé) — Task 1 (`updateSession`, `setComment`) et Task 6.
