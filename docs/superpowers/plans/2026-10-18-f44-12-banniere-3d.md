# F44.12 — Bannière animée 3D du README : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remplacer la bannière animée du README par un plan-séquence three.js de ~40 s, tourné sur la nouvelle interface, rendu aux formats de D100.

**Architecture:** Un atelier hors dépôt (page Vite + three.js) dont tout l'état est une fonction pure du temps `t` (`window.__renderAt(t)`). Un script Playwright capture les 1 200 images (30 i/s) ; ffmpeg en fait un master MP4 puis l'AVIF, le WebP et l'image fixe de D100. Le dépôt ne reçoit que les trois images, le README et la mémoire projet ; les sources partent en archive chez l'utilisateur.

**Tech Stack:** TypeScript, three.js (+ `three/examples/jsm` : `EffectComposer`, `UnrealBloomPass`, `OutputPass`, `ShaderPass`, `CSS2DRenderer`, `RoundedBoxGeometry`), Vite, Vitest, Playwright 1.63 (mêmes navigateurs que le dépôt), ffmpeg (`libx264`, `libsvtav1`, `libwebp_anim`, `libwebp`).

**Spec:** `docs/superpowers/specs/2026-10-18-f44-12-banniere-3d-design.md`

## Global Constraints

- Atelier : `/srv/AdrienGras/questionator-banniere-3d/` (hors dépôt, son propre `package.json`, pnpm). Rien de l'atelier n'entre dans le dépôt ; aucune dépendance ajoutée au `package.json` du dépôt.
- Source : 1920×1080, 30 i/s, `DURATION = 40` s, 1 200 images (`t = i / 30`, `i` de 0 à 1199). Boucle : l'image `t = 40` est identique à `t = 0`.

- Look : tokens sombres de `src/index.css` — fond `oklch(0.16 0.02 292)`, carte `oklch(0.2 0.024 292)`, bordure `oklch(0.3 0.03 292)`, texte `oklch(0.965 0.008 292)`, texte atténué `oklch(0.74 0.025 292)`, primaire rose `oklch(0.585 0.235 356)`, anneau `oklch(0.7 0.2 356)`, graphiques `oklch(0.8 0.12 215)` / `oklch(0.84 0.14 80)` / `oklch(0.76 0.16 150)` / `oklch(0.72 0.12 295)`. Polices Geist et Geist Mono (woff2 copiés depuis `node_modules/@fontsource-variable/geist*/files/` du dépôt, sous-ensembles `latin` et `latin-ext`).

## Structure de l'atelier

```
questionator-banniere-3d/
  package.json  tsconfig.json  vite.config.ts  index.html  README.md
  public/fonts/              Geist*.woff2, GeistMono*.woff2
  public/screens/            copies des captures du guide (PNG 2560×1600)
  src/
    ease.ts                  clamp01, lerp, seg, easings, rng
    timeline.ts              FPS, DURATION, BEATS, beatAt
    camera-path.ts           CamKey, cameraAt
    captions.ts              CAPTIONS, wordsVisible
    stage.ts                 renderer, composer (bloom, grain), CSS2D, textures, polices
    glyph-matter.ts          texte → nuage de fragments instanciés
    objects/                 un fichier par objet 3D réutilisable
    scenes/                  un fichier par étape : opening, prepare, draw, project, grade, stats, extras, ending
    main.ts                  __ready, __renderAt
  scripts/
    frames.ts                captures ciblées + planche
    render.ts                les 1 200 images
    check-determinism.ts     ordre de rendu, boucle, première image
    encode.sh                master, AVIF, WebP, image fixe, contrôle des seuils
  tests/                     Vitest des modules purs
  out/                       (ignoré) images, master, rendus
```

Contrat d'une étape : `export function build(stage: Stage): (t: number) => void` dans `src/scenes/<id>.ts`. La fonction rendue lit `beatAt(t)` ou ses propres bornes et ne touche que ses objets (visibilité, transformations, uniforms) ; elle masque tout hors de sa fenêtre.
