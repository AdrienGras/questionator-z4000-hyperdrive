# F44.10 — Mode clair dérivé : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** le mode clair revient, dérivé du thème sombre, avec la bascule en pied de menu et `presentation.defaultColorMode` de nouveau effectif (#152).

**Architecture :** `:root` de `src/index.css` porte les tokens clairs, `.dark` les tokens sombres (les deux exactement `THEME_TOKENS`) ; les valeurs fixes qui dépendent du mode (couleurs d'espace, lien, ombres, syntaxe, encre de catégorie) passent par des variables posées sur `html` / `html.dark`. `AppearanceProvider` perd `forcedMode` ; la vue projetée ne mémorise plus de choix et suit `defaultColorMode`. `ColorModeToggle` devient une ligne du pied de menu (menu latéral et tiroir).

**Tech Stack :** React 19, Tailwind v4 (`@theme`, `@theme inline`), base-ui (shadcn), Vitest + Testing Library, Playwright.

**Spec :** `docs/superpowers/specs/2026-10-14-f44-refonte-ui-design.md` (D102, § Contraintes) ; carte des écrans `docs/superpowers/specs/2026-10-17-f44-carte-des-ecrans.md` (§ Transverse) ; maquettes : canevas v30, page « Mode clair » (`clair/menu-bascule`, `clair/accueil`, `clair/passage-question`, `clair/projection-question`, `clair/statistiques`) ; tokens : design system v9, `project/tokens.json` (URL dans `docs/ENVIRONMENT.md`).

## Review Focus

1. **Choix « clair » mémorisé avant la refonte pour la vue projetée** (`questionator:color-mode:<id>:present`) : la vue projetée doit l'ignorer et suivre `defaultColorMode`, sinon elle reste bloquée sans bouton → test en Task 3.
2. **Config avec `theme.dark` seul, ouverte en clair** : les tokens clairs du design system s'appliquent, aucun token sombre de la config ne fuit → test en Task 3.
3. **Catégorie sans couleur** : l'encre retombe sur le repli actuel (`muted-foreground` ou `primary`), pas sur une couleur assombrie ni sur `black` → test en Task 2.
4. **Bascule puis clic immédiat sur la page** (#76) : le menu de choix est refermé, le clic suivant agit sur la page → e2e restauré en Task 4.
5. **Menu replié** : la bascule garde un nom accessible et une infobulle au focus clavier ; le focus reste sur la bascule après un choix → test en Task 4.
