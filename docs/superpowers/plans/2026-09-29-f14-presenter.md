# F14 — Mode présentateur Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une vue projetée en lecture seule, étanche par construction, pilotée depuis la vue examinateur, et le premier test Playwright à deux fenêtres dans un job CI `e2e`.

**Architecture:** `toProjectedView(session)` (pur, `src/domain/presentation/`) produit le seul type que la route `present` reçoit. La fenêtre projetée lit la base par `useSession` + `liveQuery` et décide seule de l'animation. La vue examinateur écrit `projection` par la transition `setProjection` via `usePassageActions`. Playwright (Page Object Model) vérifie synchronisation et étanchéité entre deux vraies fenêtres.

**Tech Stack:** React 19, TypeScript, Dexie (`useSession`, `updateSession`), TanStack Router, Tailwind 4, `@tabler/icons-react`, Vitest + Testing Library + fake-indexeddb, `@playwright/test` (nouveau), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-29-f14-presenter-design.md` (décision D69 dans `docs/DECISIONS.md`).

## Global Constraints

- Arborescence D59 : `domain/` sans React ni `lib/db`, `features/<x>/` n'importe aucune autre feature, imports par `@/`, pas de barrel, fichiers en kebab-case ; `pnpm deps` doit rester vert.
- Étanchéité (D30, D69) : aucun composant de `src/features/present/` ne reçoit ni n'importe le type `Session` ni `NormalizedConfig` ; `ProjectedView` est construite par liste blanche (aucun `...spread` d'un objet de la config ou d'un étudiant). Jamais dans la vue : `answer`, `tags`, commentaire, montant ou justification d'ajustement, motif de passe, `editedAt`, identifiant d'étudiant, données d'un autre étudiant.
- Note projetée (D31) : `final.final` = note finale ajustement compris ; `final` absent tant que `finalRevealedAt` n'est pas renseigné.
- Mutation de session (D67) : une transition ne modifie jamais son entrée ; sans effet, elle renvoie la même référence.
- Tout texte visible par `ui.text(...)` avec entrées fr **et** en dans `src/lib/i18n/ui-messages.ts`.
- La vue projetée n'écrit jamais en base.
- Commits gitmoji en français, au présent, emoji Unicode, suivis de `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` et `Claude-Session: https://claude.ai/code/session_011GaMaWoWjBN7xkjiNij3Jx`.
- Commandes : `pnpm vitest run <fichiers>` pendant le travail, `pnpm check` avant chaque commit.

## Review Focus

- **Changement d'étudiant projeté** : passer de A à B (B ayant déjà une question en cours) ne doit pas jouer l'animation — seul un nouveau tirage du même étudiant anime (test en Task 3 ; `StudentScreen` remonté par `key` sur l'identité affichée, Task 2).
- **Étudiant projeté réinitialisé** (F11) pendant que la vue est ouverte : retour à « 1 / 3 », grille réactivée, sans animation (test en Task 3).
- **Popup bloquée** (`window.open` renvoie `null`) : message dans la vue examinateur, pas d'exception (test en Task 4).
- **Correction de note après révélation** : la note affichée suit sans être masquée (test en Task 2).
- **Session supprimée pendant que la vue est ouverte** : écran « introuvable », pas de plantage (test en Task 2).
