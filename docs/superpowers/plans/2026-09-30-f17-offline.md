# F17 — Hors ligne — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une PWA installable dont le service worker pré-cache tout, utilisable réseau coupé après un premier chargement, avec une mise à jour proposée et jamais imposée.

**Architecture:** vite-plugin-pwa (`generateSW`, `registerType: 'prompt'`, `clientsClaim`) produit `sw.js` et le manifeste. Un store technique `lib/pwa/pwa-update.ts`, alimenté par `registerSW` de `virtual:pwa-register`, expose un état observable (`current` / `update-ready`) consommé par une pastille globale (vue examinateur) et par un hook de rechargement (vue projetée). `pnpm check:precache` garantit en CI que tout `dist/` est pré-caché.

**Tech Stack:** Vite 8 (Rolldown), vite-plugin-pwa 1.3.0 + workbox-window, React 19, TanStack Router (hash history), Dexie, Vitest 5, Playwright (Chromium).

**Spec:** `docs/superpowers/specs/2026-09-30-f17-offline-design.md` (D72 dans `docs/DECISIONS.md`). Le lire avant chaque tâche.

## Global Constraints

- Arborescence D59 (`docs/CONVENTIONS.md` § « Arborescence et imports ») : `lib/pwa/` = technique, n'importe ni `domain/` ni `lib/db/` ; imports `@/…`, pas de `../`, pas de barrel, fichiers en kebab-case, tests colocalisés.
- `base` : `/questionator-z4000-hyperdrive/` (déjà dans `vite.config.ts`), dont héritent `scope` et `start_url`.
- Service worker désactivé en dev ; enregistré en prod seulement, par `import()` dynamique (hors bundle initial).
- `registerType: 'prompt'`, `injectRegister: false`, `clientsClaim: true`, `cleanupOutdatedCaches: true` ; ni `skipWaiting` en config, ni cache à l'exécution, ni `navigateFallback`.
- `globPatterns` : `**/*.{js,css,html,json,csv,svg,png,webp,woff2}`.
- Jamais de rechargement automatique d'un onglet examinateur ; la vue projetée n'affiche jamais la pastille.
- Libellés UI : `update_available` = « Nouvelle version disponible » / « New version available » ; `update_reload` = « Recharger » / « Reload ».
- Commits gitmoji en français, présent, emoji Unicode, avec les deux lignes d'attribution (`Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` et `Claude-Session: https://claude.ai/code/session_01MuZBBR1c8YAVppDfkPmP1g`).
- `pnpm check` vert à la fin de chaque tâche (format, lint, deps, types, tests). Toutes les commandes préfixées par `rtk`.

## Review Focus

- Premier chargement : le `controllerchange` provoqué par `clientsClaim` ne doit pas afficher la pastille (Task 1, test dédié).
- `versionchange` et `controllerchange` simultanés dans la vue projetée : un seul rechargement, pas de boucle (Task 1, test dédié).
- « Recharger » quand l'enregistrement a échoué ou qu'un autre onglet a déjà activé la version : `location.reload()`, pas d'exception (Task 1).
- Un chunk trop gros (Tabler ~2,37 Mo) écarté silencieusement du pré-cache : `check:precache` doit échouer en le nommant (Task 4, test dédié) et le vrai build doit passer.
- Pastille visible sur `/present/…` ou en même temps que le bandeau `outdated` (Task 3, tests dédiés).

  - `export function usePwaUpdate(update?: PwaUpdate): { status: PwaStatus; applyUpdate: () => Promise<void> }`
