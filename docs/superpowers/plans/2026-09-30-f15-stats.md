# F15 — Statistiques de session — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `computeStats(session)` pur dans `src/domain/stats/` et un écran `#/session/$sessionId/stats` qui l'affiche, Recharts confiné au chunk de cette route.

**Architecture:** un fichier par bloc de statistiques dans `domain/stats/`, composés par `compute-stats.ts` à partir des `computeScores` / `studentStatus` du moteur. Une feature `features/stats/` montée par une route non imbriquée ; l'histogramme utilise le composant `chart` de shadcn. Un script lit le manifeste Vite pour prouver que Recharts reste hors du bundle initial.

**Tech Stack:** React 19, TanStack Router (file-based, `autoCodeSplitting`), Vitest + Testing Library, shadcn v4 (base-ui) + Recharts, dependency-cruiser, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-30-f15-stats-design.md` (décisions D70). Lire la spec avant chaque tâche : ses tableaux « Définitions » et « Écran » font foi.

## Review Focus

1. **Note égale à `finalScale`** (20/20, 100/100, 12,5/12,5) : elle tombe dans la dernière barre, jamais dans une barre fantôme au-delà. → test dans la tâche 1.
2. **`finalScale` > 20 non multiple de 20** (/33, /100 avec une note 99,999) : l'indice se calcule en entiers, sans pas décimal flottant ; aucune note ne saute de barre. → test dans la tâche 1.
3. **Motif de skip libre qui duplique un motif configuré** à la casse près, ou motif absent : « Hors programme » et « hors programme » restent deux lignes (pas de normalisation cachée), `undefined` → `null` en dernier. → test dans la tâche 2.
4. **Étudiant terminé puis marqué absent** : il sort des notes et des stratégies, et ses attempts (remis à zéro par `setAbsent`) disparaissent ; le test construit directement un absent **avec** attempts résiduels pour vérifier que `categories`/`questions` les ignorent aussi. → test dans la tâche 2.
5. **Question tirée dont l'id n'existe plus dans la config** (backup incohérent) : `topDrawn` la garde avec son id, l'écran affiche l'id au lieu du titre sans planter. → tests dans les tâches 2 et 5.
