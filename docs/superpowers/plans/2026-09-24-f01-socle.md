> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un dépôt Vite + React + TypeScript 7 prêt à développer, avec une app vide routée par hash, un lint type-aware, des tests, et une CI qui vérifie puis déploie sur GitHub Pages.

**Architecture:** SPA Vite 8 servie sous le sous-chemin `/questionator-z4000-hyperdrive/`. TanStack Router en routing file-based avec `createHashHistory` (GitHub Pages n'a pas de fallback SPA). ## Review Focus

- **Rechargement sur une URL profonde sous le sous-chemin** (`…/questionator-z4000-hyperdrive/#/nimporte-quoi`) : les assets doivent se charger depuis `/questionator-z4000-hyperdrive/assets/…`, jamais depuis `/assets/…`. Épinglé par l'étape CI « Vérifier la base des assets » (Task 5).
- **`routeTree.gen.ts` périmé commité** : si quelqu'un ajoute une route sans commiter le fichier régénéré, la CI doit échouer. Épinglé par l'étape CI « Vérifier que l'arbre de routes est à jour » (Task 5).
- **Lint réellement type-aware** : une promesse flottante doit faire échouer `pnpm lint`, sinon tsgolint n'est pas branché. Épinglé par l'étape de vérification de Task 4.
- **Clone neuf** : `nvm use && pnpm install --frozen-lockfile && pnpm check` doit passer sans étape manuelle (lockfile commité, `allowBuilds` complet). Épinglé par le job CI `check` (Task 5), qui part toujours d'un clone neuf.
- **Route inconnue** : `#/nimporte-quoi` affiche le composant 404 de l'app et un lien de retour, pas une page blanche. Épinglé par le test `routes.test.tsx` (Task 3).

```tsx
import { createMemoryHistory, RouterProvider } from '@tanstack/react-router'
import { render, screen } from '@testing-library/react'
import { expect, test } from 'vitest'
import { createAppRouter } from '@/router'

function renderAt(path: string) {
  const router = createAppRouter(createMemoryHistory({ initialEntries: [path] }))
  render(<RouterProvider router={router} />)
}

test("la route / affiche l'accueil", async () => {
  renderAt('/')
  expect(
    await screen.findByRole('heading', { name: 'Questionator Z-4000 Hyperdrive' }),
  ).toBeInTheDocument()
  expect(screen.getByRole('button', { name: 'Commencer' })).toBeInTheDocument()
})

test('une route inconnue affiche la page 404 avec un lien de retour', async () => {
  renderAt('/nimporte-quoi')
  expect(await screen.findByRole('heading', { name: 'Page introuvable' })).toBeInTheDocument()
  expect(screen.getByRole('link', { name: "Retour à l'accueil" })).toHaveAttribute('href', '/')
})
```

- [ ] **Step 2: Écrire le workflow**

`.github/workflows/ci.yml` (remplacer chaque `@vN` par la majeure relevée) :

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:

permissions:
  contents: read

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@vN
      - uses: pnpm/action-setup@vN
      - uses: actions/setup-node@vN
        with:
          node-version-file: .nvmrc
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - name: Format
        run: pnpm format:check
      - name: Lint
        run: pnpm lint
      - name: Types
        run: pnpm typecheck
      - name: Tests
        run: pnpm test
      - name: Build
        run: pnpm build
      - name: Vérifier que l'arbre de routes est à jour
        run: git diff --exit-code -- src/routeTree.gen.ts
      - name: Vérifier la base des assets
        run: grep -q '/questionator-z4000-hyperdrive/assets/' dist/index.html
      - uses: actions/upload-pages-artifact@vN
        if: github.event_name == 'push' && github.ref == 'refs/heads/main'
        with:
          path: dist

  deploy:
    needs: check
    if: github.event_name == 'push' && github.ref == 'refs/heads/main'
    runs-on: ubuntu-latest
    permissions:
      pages: write
      id-token: write
    concurrency:
      group: pages
      cancel-in-progress: false
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@vN
```
