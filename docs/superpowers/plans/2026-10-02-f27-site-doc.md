# F27 — Site de documentation (socle) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un site VitePress en français publié sous `…/questionator-z4000-hyperdrive/docs/` avec l'app, des sections squelettes « Guide » et « Contribuer », et un lien « Aide » dans l'en-tête de l'app.

**Architecture:** Sources dans `site/`, build VitePress vers `dist/docs/` après le build de l'app, dans le même artefact Pages. Le service worker de l'app laisse passer `/docs/` au réseau et ne pré-cache rien de la doc ; `check:precache` en tient compte.

**Tech Stack:** VitePress `2.0.0-alpha.20` (Vite 8), React 19, vite-plugin-pwa / Workbox, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-02-f27-site-doc-design.md`

## Global Constraints

- `vitepress` en devDependency, version **exacte** `2.0.0-alpha.20` (pas de `^`).
- Base de la doc : `/questionator-z4000-hyperdrive/docs/` ; sortie : `dist/docs/` ; sources : `site/` (jamais `docs/`).
- Toute l'interface de la doc en français ; `lang: 'fr'`.
- Commits gitmoji en français, emoji Unicode, terminés par :
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_016cZs3fAZqobifoZLYBXkgD
  ```
- Préfixer les commandes shell par `rtk` (ex. `rtk pnpm test`, `rtk git commit`).
- Formateur : oxfmt (`pnpm format`), pas Prettier ; `**/*.md` reste ignoré.
- Fichiers en kebab-case, imports `@/` dans `src/`, pas de barrel.
- Ne jamais `Read` un `docs/*.md` en entier : `grep -n '^## '` puis plage.

## Review Focus

1. **`…/docs` sans barre finale** : avec le service worker actif, l'URL doit afficher la doc, pas l'app. Le motif de `navigateFallbackDenylist` doit donc être `/\/docs(?:\/|$)/` (et non `/\/docs\//`) ; e2e en Tâche 4.
2. **Rechargement d'une page profonde** (`docs/guide/prise-en-main.html`) sous service worker : la page de doc, pas l'app ; e2e en Tâche 4.
3. **Routes de l'app inchangées** : le motif ne doit capturer aucune navigation de l'app (routage par hash, chemin = base seule) ; `e2e/offline.spec.ts` doit rester vert (Tâche 4).
4. **Ordre des builds** : `vite build` vide `dist/` ; `docs:build` doit venir après dans la CI et dans la commande `webServer` de Playwright (Tâche 4).
5. **Ancien service worker déjà installé** (mode `prompt`) : tant que l'utilisateur n'a pas accepté « Recharger », l'ancien SW sert l'app sur `/docs/`. Non testable à coût raisonnable ; à consigner dans QUIRKS (Tâche 5).
