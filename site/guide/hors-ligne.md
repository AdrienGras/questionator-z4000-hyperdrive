# Hors ligne et installation

L'application est faite pour fonctionner sans réseau, par exemple dans une salle d'examen sans wifi. Il faut simplement l'avoir chargée une première fois avec une connexion.

## Utiliser l'application hors ligne

1. **Ouvrez l'application une fois en ligne**, dans le navigateur que vous utiliserez pour l'oral. Le navigateur télécharge alors tout ce dont elle a besoin.
2. **Attendez le message « Prête pour le hors ligne : l'application fonctionne désormais sans réseau. »** Il s'affiche en bas à droite de l'écran, une fois le téléchargement fini. Cliquez sur « OK » pour le fermer.
3. **Coupez le réseau si vous voulez.** Rouvrez ensuite l'application à la même adresse.

Sans réseau, vous pouvez créer une session, faire passer des étudiants, ouvrir la vue projetée et exporter en Excel. La coloration du code dans les questions fonctionne aussi. Le message « Prête pour le hors ligne » ne s'affiche qu'au premier chargement.

Vérifiez cela **avant** le jour de l'oral : coupez le réseau, rechargez la page et ouvrez une session de test.

Les limites :

- **Les images distantes ne s'affichent pas.** Une question qui contient une image dont l'adresse est sur internet (`https://…`) ne la montre pas sans réseau. Le reste de la question s'affiche normalement.
- **Cette documentation n'est pas disponible hors ligne.** Elle se consulte en ligne. Gardez ouverte ou imprimez la page dont vous avez besoin avant de partir.
- **Chaque navigateur a ses propres données.** Les sessions créées dans un navigateur n'existent pas dans un autre. Voir [Créer, reprendre et importer une session](./sessions).

## Installer l'application

Chrome et Edge proposent d'installer l'application comme un programme : elle s'ouvre alors dans sa propre fenêtre, sans barre d'adresse. Cherchez l'icône d'installation à droite de la barre d'adresse, et suivez les indications du navigateur.

L'installation est facultative. L'application fonctionne de la même façon dans un onglet normal.

## Mettre à jour l'application

Quand une nouvelle version est publiée, une pastille « Nouvelle version disponible » apparaît en bas à droite, avec un bouton « Recharger ». L'application la cherche toute seule, toutes les heures, au retour sur l'onglet et au retour du réseau.

La nouvelle version **n'est jamais appliquée d'office**. Vous décidez du moment : cliquez sur « Recharger » entre deux passages, jamais au milieu d'une question. Vos sessions restent enregistrées dans le navigateur.

La pastille ne s'affiche pas dans la vue projetée. Celle-ci se recharge toute seule quand vous avez appliqué la mise à jour depuis l'écran de passage.
